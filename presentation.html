timeline TempoSheet

Module complémentaire bilingue et gratuit pour Google Workspace. Automatisez le suivi du temps via Google Agenda™ et Google Sheets™.

Version 1.2.0 Open Source · MIT 🌍 FR / EN

info Présentation générale

TempoSheet est une solution légère et professionnelle destinée aux freelances et aux petites équipes. Pourquoi payer pour un outil externe alors que l'infrastructure Google Workspace dispose déjà de tout le nécessaire ?

Enregistrez vos heures en ajoutant des #tags à vos événements Google Agenda. L'extension extrait vos données et génère automatiquement des rapports structurés dans Google Sheets.

auto_awesome Fonctionnalités clés

event

Google Agenda™ natif

Suivez votre temps directement depuis votre agenda. Aucun tableau de bord externe requis.

tag

Tags intelligents

Format simple : #projet dans le titre. Supporte toutes les langues : #مشروع, #プロジェクト…

timer

Chronomètre intégré

Barre latérale Material Design 3 avec démarrage/arrêt en temps réel et raccourci Espace.

description

Export en un clic

Rapport consolidé généré dans un nouvel onglet Google Sheets avec mise en forme automatique.

email

Envoi par e-mail

Envoyez votre rapport directement par e-mail au format HTML depuis le menu de l'extension.

public

Fuseaux horaires

Les périodes sont calculées dans le fuseau de votre agenda : votre mois reste votre mois, où que vous soyez.

route Comment ça marche ?

1

Enregistrez votre temps

Créez des événements dans votre Google Agenda. Structurez le titre avec un tag suivi d'une description optionnelle :

#projet1 Phase de recherche et développement
2

Générez le rapport

Ouvrez Google Sheets → Extensions → TempoSheet → Créer un rapport. Choisissez calendrier et période, puis validez.

3

Partagez le résultat

Envoyez le rapport par e-mail au format HTML ou exportez-le en PDF depuis Google Sheets.

architecture Architecture technique

Le projet repose entièrement sur l'écosystème Google Apps Script, sans hébergement externe ni base de données tierce.

CalendarApp

Lecture des événements et création via le chronomètre.

SpreadsheetApp

Génération et mise en forme des rapports.

MailApp

Envoi du rapport par e-mail HTML.

PropertiesService

Persistance de l'état du chronomètre entre les sessions.

HTML5 + i18n

Interface bilingue côté client et serveur (FR/EN).

V8 Runtime

Support Unicode complet avec regex \p{L} pour tous les alphabets.

terminal Déploiement développeur

Pour déployer ce script sur votre propre environnement avec l'outil Clasp :

# 1. Cloner le dépôt
git clone https://github.com/FabriceFx/TempoSheet.git

# 2. Installer clasp
npm install -g @google/clasp

# 3. Se connecter à Google
clasp login

# 4. Créer et déployer
clasp create --type sheets --title "TempoSheet"
clasp push
