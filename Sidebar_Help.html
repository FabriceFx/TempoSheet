TempoSheet

Cet outil transforme votre Google Agenda en un système de suivi du temps.

Premiers pas :

  • Créez des événements dans le Google Agenda de votre choix.
  • Pour qu'un événement soit reconnu, son titre doit contenir un #tag identifiant le projet : #NomDuProjet Description de la tâche Le #tag peut aussi se trouver ailleurs dans le titre : « Réunion #projet1 hebdomadaire ». Le nom du projet accepte toutes les langues : #مشروع, #プロジェクト, #Проект…
  • Le reste du titre devient la description de la tâche. Sans description, la tâche sera nommée « Tâches diverses ».
  • Un événement « journée entière » est comptabilisé forfaitairement à 7 heures par journée couverte.
  • Allez dans le menu Extensions → TempoSheet → Créer un rapport.
  • Sélectionnez le calendrier source, la période souhaitée et cliquez sur Créer le rapport.
