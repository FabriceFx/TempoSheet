Générateur de Rapport de Temps

Cet outil transforme votre Google Agenda en un système de suivi du temps.

Premiers pas :

  • Créez des événements dans le Google Agenda de votre choix.
  • Pour qu'un événement soit reconnu, le titre doit suivre ce format :
    #NomDuProjet Description de la tâche
  • La description de la tâche est optionnelle. Sans description, la tâche sera nommée "Tâches diverses".
  • Allez dans le menu Extensions -> Générateur de rapport de temps -> Créer un rapport.
  • Sélectionnez le calendrier source, la période souhaitée et cliquez sur Créer le rapport.
